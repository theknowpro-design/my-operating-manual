# Profit Engine AI PDF Generator

Official PDF generator for **Profit Engine AI** / Money Maker App.

This package follows the **Master PDF Layout Spec** (`layout.json`) and embeds the **Read Me** teal book-head logo on every cover page by default (`branding.json` + `assets/Teal Read Me Logo.png`).

## Structure

```text
pdf-engine/
  assets/
    Teal Read Me Logo.png
  layout.json
  branding.json
  (content mapper: ../src/pdf-engine/content_mapper.js)
  pdf_engine.js
  export_manager.js
  README.md
```

## How the PDF engine works

1. **`content_mapper.js`** turns Money Maker generation output (or plain user text objects) into clean section blocks:
   - Executive Summary
   - Business Model
   - Revenue Streams
   - Growth Strategy
   - Marketing Strategy
   - Pricing Model
   - Action Plan
   - Operational Notes
   - Digital Visibility Strategy
   - Metadata
   - Appendices (optional)
2. **`pdf_engine.js`** loads `layout.json` + `branding.json`, renders the **Cover Page** (logo + title + subtitle), then renders each business section with typography/spacing rules.
3. **`export_manager.js`** names the file, injects export metadata, and downloads/saves the PDF.

Filename format:

```text
ProfitEngineAI_<Title>_<YYYY-MM-DD>.pdf
```

## Feeding content into the engine

Pass either:

- a Money Maker generation `result` object (`method`, `formatted`, `meta`, etc.), or
- a plain object with fields like `title`, `niche`, `category`, `offer`, `pricing`, `actionPlan`, …

### Browser example

```js
import { exportProfitEnginePdf } from './pdf-engine/export_manager.js';

await exportProfitEnginePdf(generationResult, {
  title: generationResult.method?.title,
});
```

### Map sections only

```js
import { mapAllSections } from '../src/pdf-engine/content_mapper.js';

const content = mapAllSections(generationResult);
console.log(content.sections);
```

### Generate without auto-download

```js
import { createPdfExport } from './pdf-engine/export_manager.js';

const { filename, bytes, blob } = await createPdfExport(generationResult);
```

## Generating a PDF

From the Money Maker App action bar export path (recommended integration):

1. Generate a plan in the app.
2. Call `exportProfitEnginePdf(result)` from the export handler.
3. The branded PDF downloads automatically.

Stand-alone browser usage:

```js
import { exportProfitEnginePdf } from '/pdf-engine/export_manager.js';

await exportProfitEnginePdf({
  title: 'Side Hustle Checklist Offer',
  niche: 'Side Hustles',
  category: 'Affiliate Marketing',
  offer: 'A practical five-step checklist PDF for daily affiliate progress.',
  pricing: 'Entry pricing in the $9–$49 range.',
  actionPlan: '1. Define the checklist outcome.\n2. Build the asset.\n3. Publish and validate.',
});
```

## Integrating with Money Maker App

Suggested wiring inside `ui/exports.js` (or the Export PDF action):

```js
import { exportProfitEnginePdf } from '../pdf-engine/export_manager.js';

export async function exportPdf(result, meta = {}) {
  await exportProfitEnginePdf(result, {
    title: result?.method?.title || meta.exportTitle || 'Profit Plan',
  });
}
```

Branding defaults:

- Logo: `assets/Teal Read Me Logo.png` (teal book-head “Read Me”)
- Accent: `#008080`
- Footer: `Generated by My Operating Manual`
- Logo on cover: **yes** (top-center, 120px)
- Logo on footer: **no**

Override branding at export time:

```js
await exportProfitEnginePdf(result, {
  branding: {
    footerText: 'Prepared for Client Review',
    accentColor: '#2A4B7C',
  },
});
```

## Running the stand-alone generator

1. Start the Money Maker Vite app (`npm run dev`) so JSON + logo assets can be fetched as ES modules.
2. Import `export_manager.js` from a page/console script, or wire it into Export PDF.
3. Provide generation data and call `exportProfitEnginePdf(...)`.

Layout rules enforced by `layout.json`:

- US Letter
- Margins: 0.75in top/bottom, 1in left/right
- Heading/body sizes: H1 30 / H2 22 / H3 16 / Body 13
- Line height 1.5, paragraph spacing 14, section spacing 24

## Notes

- Cover page always attempts to embed the teal Read Me logo when `includeLogoOnCover` is `true`.
- jsPDF currently uses Helvetica as the embedded standard font (Inter metrics are represented for layout targeting; swap to a custom font pack if exact Inter glyph embedding is required).
- Appendices appear only when bonus/time-block/extra appendix content exists.
